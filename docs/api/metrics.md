# `musyn.metrics`

Quality metrics for comparing reconstructed data (`W @ C`) against the
original matrix, or extracted synergies against a ground truth.
{func}`~musyn.metrics.vaf`, {func}`~musyn.metrics.r_squared`, and
{func}`~musyn.metrics.quality_ratio` are also available directly as
`musyn.vaf`, `musyn.r_squared`, and `musyn.quality_ratio` — see
{doc}`public`.
