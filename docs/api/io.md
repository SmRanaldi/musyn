# `musyn.io`

Loaders and writers for common EMG data formats. Not imported into the
top-level `musyn` namespace — use `import musyn.io` or
`from musyn.io import ...` explicitly.

## Loading

```{autofunction} musyn.io.load_csv
```

```{autofunction} musyn.io.load_mat
```

```{autofunction} musyn.io.load_npz
```

## Saving

```{autofunction} musyn.io.save_npz
```

```{autofunction} musyn.io.save_results
```
